# AI-Agents 🤖

A powerful collection of AI agents built with CrewAI that leverage large language models to automate research tasks and information gathering.

- [Overview](#overview)
- [Features](#features)
- [Prerequisites](#prerequisites)

## 🎯 Overview

AI-Agents is a framework for building autonomous AI agents using CrewAI. These agents can perform complex tasks like researching technology news, analyzing information, and providing summarized insights. The project demonstrates how to integrate multiple tools (like DuckDuckGo search) with LLMs to create intelligent, task-driven agents.

## ✨ Features

- 🔍 **Autonomous Research** - Agents independently search and analyze information
- 🧠 **LLM-Powered** - Support for multiple LLM providers (Groq, Google Gemini, OpenAI)
- 🔧 **Extensible Tools** - Easy integration with web search, APIs, and custom tools
- 📊 **Structured Output** - Organized, actionable results from agent tasks
- 🚀 **Production-Ready** - Built with CrewAI framework for stability and scalability

## 📦 Prerequisites

Before you begin, ensure you have the following:

- **Python 3.8+** - Required for running the agents
- **Jupyter Notebook** - For running .ipynb files
- **pip** - Python package manager
- **API Keys** - One or more LLM provider keys (Groq, Google Gemini, or OpenAI)

### Supported LLM Providers

- **Groq** (Recommended for free tier): `groq/llama-3.3-70b-versatile`
- **Google Gemini**: `gemini/gemini-2.0-flash` or `gemini/gemini-1.5-flash`
- **OpenAI**: `gpt-4` or `gpt-3.5-turbo`
